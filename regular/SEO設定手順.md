# FCS数学教室 検索対策（SEO）設定手順

ページの中身（`regular_premium.html`）はすでに検索向けに整えてあります。
ここでは、ページの外で行う「設定」を、効果の大きい順に並べています。

## 1. ページを差し替える（必須）

1. `regular_premium.html`（Shift_JIS）を、現在の `regular.html` と同じ名前・同じ場所でアップロードします。
   - ファイル名を変えると、これまでの検索評価が引き継がれません。
2. ページ先頭の `<link rel="canonical" …>` のコメントを外し、このページの公開URLを書き入れます。
   - `www.fcs9981.co.jp` と `fcs9981.sakura.ne.jp` の両方で同じページが見られる場合、どちらを正式にするかを決めて、そちらのURLを書きます。
3. ロゴ画像 `fcs.gif` と `261026.jpg` が同じフォルダにあることを確認します。

## 2. Googleビジネスプロフィールに登録する（地域検索で最も効果が大きい）

「春日市 数学 塾」「大野城 塾 高校生」のような地域名つきの検索では、地図欄（Googleマップ）が検索結果の一番上に出ます。ここに載るには登録が必要です。

1. https://www.google.com/business/ で「FCS数学教室」を登録します。
2. カテゴリは「学習塾」、追加カテゴリに「数学教室」などを選びます。
3. 公民館で開講している場合は「店舗なし（訪問・出張型）」を選び、サービス提供地域に「春日市・大野城市・筑紫野市・福岡市南区・久留米市」を入れます。
4. 電話番号 092-919-2200、ウェブサイトにこのページのURLを入れます。
5. 説明文には、ページ冒頭の「当教室について」の文章を使えます。
6. 保護者の方・卒業生の方に口コミを書いていただくと、順位が上がりやすくなります。

## 3. Google Search Console に登録する

検索での表示回数・順位・不具合を確認できる、Google の無料ツールです。

1. https://search.google.com/search-console でサイトを登録します（所有確認はHTMLファイルのアップロードが簡単です）。
2. 「URL検査」にこのページのURLを入れ、「インデックス登録をリクエスト」を押します。
3. 数週間後から「検索パフォーマンス」で、どんな言葉で検索されたかが分かります。

## 4. サイト全体で行うとよいこと

- **https 化**：さくらのレンタルサーバでは無料SSL（Let's Encrypt）が使えます。http のままだと、ブラウザに「保護されていない通信」と表示され、保護者の方の印象を下げます。
- **ほかのページの白文字を削除**：`top2020.html` などにも、背景と同じ色の文字（隠しテキスト）があれば削除してください。Google の規約違反として評価が下がる原因になります。
- **教室ページ（ooh.html、ksg.html など）に住所を書く**：各教室のページに「福岡県春日市○○ ○-○ 春日原公民館」のように住所を文字で書くと、地域名での検索に強くなります。
- **SNSのプロフィールにこのページのURLを載せる**：Facebook・YouTube・X・Threads・Instagram の自己紹介欄に、このページへのリンクを入れます。

## 5. 確認していただきたい内容

- 教室一覧の「地域」（福岡市南区・春日市・大野城市・筑紫野市・久留米市）は、会場名から判断して書きました。違っていれば直してください。
- 「三宅地録会館」の表記（元ページの画像からの書き起こし）。
- 画像が届いていない3か所（コメント「★★★ 画像なし」の部分）。
