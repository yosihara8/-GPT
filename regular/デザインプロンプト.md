# デザインプロンプト（格式・高級感のある塾ページ）

以下をそのまま Claude Code に貼り付けて使えます。
`【 】` の部分は、作るページに合わせて書き換えてください。

---

## プロンプト

【 】のHTMLページを、次のデザイン仕様で作ってください。
内容（文章・リンク）は【元のファイル名／貼り付けた文章】から一切変えずに使い、見た目と並べ方だけを整えてください。

### 目指す印象

- 格式が高く、高級感があり、厳正な教育機関に見えること。
- 読み手は、中学生・高校生の子を持つ40代の保護者（主に母親）。難関大学への進学や、理数系をしっかり学ばせたいと考え、文章をじっくり読む人。
- 「AIが作ったっぽさ」を出さない。次は使わないこと：
  - 角の丸いカード、影（box-shadow）、グラデーション、絵文字、アイコンの丸い背景
  - カラフルなタグ・ピル型のボタン、派手な原色
  - 英語の飾り見出し（「OUR SERVICE」など）
- 代わりに、細い罫線・広い余白・明朝体・漢数字で、上質な印刷物（学校案内のパンフレット）のような落ち着きを出す。

### 文字

- 書体は明朝体のみ。
  `font-family: "Noto Serif JP", "游明朝", "Yu Mincho", "YuMincho", "Hiragino Mincho ProN", "HG明朝E", serif;`
  Google Fonts から Noto Serif JP（400 と 600）を読み込む。
- 本文：17px（PC は 17.5px）、行間 2.0、字間 0.04em。
- 見出し（h2）：1.5rem、太さ 600、字間 0.14em、濃紺。
- 太字は 600 まで（700 以上は使わない）。
- 長い文章は段落ごとに `<p>` で分け、段落の頭を1文字下げる（text-indent: 1em）。

### 色

```css
:root {
  --paper: #faf8f3;     /* 背景：生成り（白すぎない紙の色） */
  --white: #ffffff;     /* 交互のセクション背景・表の地 */
  --ink: #23211e;       /* 本文 */
  --sub: #5c574f;       /* 補足・注記 */
  --navy: #1b2a47;      /* 主色：濃紺（見出し・ボタン・ヘッダー） */
  --navy-deep: #121d33; /* ボタンを押したとき */
  --gold: #8f7330;      /* 差し色：金（小見出し・罫線のアクセント・記号） */
  --gold-light: #c9b27a;/* 濃紺の上に乗せる金 */
  --rule: #d9d1bf;      /* 罫線 */
  --rule-soft: #ebe5d8; /* 薄い罫線 */
}
```

- 使う色はこの表の中だけにする。赤・緑・SNSのブランド色は使わない。
- 強調は色ではなく、太字か金の下線（border-bottom: 1px solid var(--gold)）で行う。

### レイアウト

- 本文の最大幅 760px、中央寄せ、左右の余白 20px（スマホは 18px）。
- セクションごとに上下 64px／56px の余白をとり、下に 1px の罫線を引く。
- 背景は 生成り と 白 を交互にして、章の切り替わりを示す。
- 章見出しは中央揃えで、次の3段にする。
  1. 金の小さな文字（0.85rem、字間 0.3em）で章名（例：「指導方針」「進学実績」）
  2. 濃紺の h2
  3. 幅 40px・高さ 1px の金の線
- スマホ（〜719px）とPC（720px〜）の2段階で切り替える。横スクロールが出ないこと。

### 部品

**ヘッダー**：濃紺の帯（高さ 56px）。左に塾名（白、字間 0.2em）、右に電話番号（金 #c9b27a）。

**冒頭（ファーストビュー）**
- 中央揃え。ロゴ → 金の小文字（例：「平成五年開講」）→ h1 → キャッチコピー → 要点の表 → ボタン2つ。
- h1 は「地域名＋業種」を小さく添えて、その下に塾名を大きく（PC 2.4rem、スマホ 1.7rem、字間 0.18em）。
- 要点の表：開講年・指導形態・月謝・入会金・無料体験 などを、細い罫線で区切った枡目に並べる（PCは横5列、スマホは2列で最後の1つは横いっぱい）。項目名は小さく灰色、値は濃紺の太字。

**ボタン**
- 角は丸めない（border-radius: 0）。
- 主ボタン：濃紺の塗り＋白文字。押すと濃い紺＋金文字。
- 副ボタン：白地＋濃紺の 1px 枠。押すと濃紺の塗り＋白文字。
- 上下 15px の余白、字間 0.12em。2行目に小さな補足（電話番号・メールアドレスなど）を添えられる。

**リンク一覧**：罫線で区切った行に、左に項目名、右端に金の「›」。PDF などの補足は小さく2行目に。

**お知らせ枠**：白地、1px の罫線、上辺だけ 3px の濃紺。中の日時・場所・持ち物は罫線の表（見出し列は濃紺の太字）。

**特長**：左に大きな金の漢数字（一・二・三）と縦の罫線、右に小見出しと説明文。

**引用・強調の段落**：左に 2px の金の縦線を引き、字下げなし。

**料金表**：罫線の表。見出し列はうすいベージュ（#f3efe5）の地に濃紺の太字。

**教室一覧**：表にする。教室名（濃紺の太字リンク＋金の「›」）、その下に会場名（小さく灰色）、右の列に地域名。

**学校別の授業メモ**：罫線で区切った行。1行目に学校名（濃紺の太字）、2行目に単元名のリンクを「／」で区切って並べる。

**Q&A**
- 罫線で区切った縦の並び。カードにはしない。
- 左に「問」（濃紺）と「答」（金）の一文字を置き、右に質問（h3）と回答。
- 追記は、生成り地に薄い罫線の枠で一段下げて表示し、金の小さな「追記」ラベルを付ける。

**在籍校・進学先の一覧**：罫線区切りのリスト（PCは2段組）。大学名は濃紺の太字、学部は小さく灰色で横に並べる。

**年度別の実績**：`<details>` で開閉。見出しは「令和8年 入試 現役進学実績」のように元号部分を金色にし、右端に金の「＋／－」。最新年度だけ最初から開いておく。各行は「大学・学部　←出身校（小さく灰色）」。

**SNS**：埋め込み（タイムラインやウィジェット）は使わない。読み込みが止まって「グルグル」が出るため。代わりに主ボタン2つ（例：「Instagramで見る」「Xで見る」）と、白地・濃紺枠のボタン（3列）を並べる。

**お問い合わせ**：中央に電話番号を大きく（1.9rem、濃紺、太字）、その下にメール、主ボタンと副ボタン。

**フッター**：濃紺の地、塾名（白、字間 0.25em）、地域名と電話番号（金）。

**スマホ下部の固定ボタン**：画面下に濃紺の帯を固定し、「電話で相談する」「メールで問い合わせ」の2つを並べる（上辺に金の細線、間に白の細い縦線）。PCでは表示しない。

### 検索対策（ページの中で必ず入れること）

- `<!DOCTYPE html>`、`<html lang="ja">`、`<meta name="viewport" content="width=device-width, initial-scale=1">`
- `<title>`：「地域名＋業種＋塾名｜強み（地域名を列挙）」の形（例：「福岡の数学専門塾 ○○教室｜高校数学の先取り・大学受験（春日・大野城・筑紫野・久留米）」）。
- `meta description`：地域・対象・指導の特長・実績・料金を、自然な文章で 120 字前後。
- h1 は1つだけ。地域名と業種を含める。
- 構造化データ（JSON-LD、`EducationalOrganization`）に、塾名・電話・メール・開講年・対象地域・SNSのURLを入れる。
- OGP（og:title、og:description、og:type、og:locale、og:site_name）。
- canonical は公開URLが決まってから入れる（分からなければコメントで空けておく）。
- 背景と同じ色の文字（隠しテキスト）は絶対に入れない。
- 画像には内容を表す alt を付け、下のほうの画像は `loading="lazy"` にする。
- 年号には元号を添える（「8年入試」→「令和8年入試」）。

### 文字コード

- サーバーが Shift_JIS の場合は、最後に Shift_JIS（cp932）で保存し、meta の charset も Shift_JIS にする。
- その場合、Shift_JIS にない記号（›、絵文字など）は本文に直接書かず、CSS の `content: "\203A"` のように文字コードで書く。

### 仕上げの確認

- スマホ幅（390px）とPC幅（1280px）でスクリーンショットを撮り、横スクロールがないこと、文字や枠が崩れていないことを確認する。
- 元の内容（文章・リンク・実績の件数）が減っていないことを確認する。
