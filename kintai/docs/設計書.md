# ミセカン 設計書（試作版 v0.2）

店長1人が使う「管理画面」と、従業員が自分のスマホで使う「従業員アプリ」をひとつにまとめた店舗管理ツールです。
この試作版は、画面と計算の流れを確かめるためのものです。実際の店で使うには、下の「作り方の形式」の B か C に進めてください。

---

## 1. 画面の整理（ページとタブ）

試作版 v0.2 から、**管理者ページ**と**従業員ページ**を別のファイルに分けました。同じ端末・同じブラウザで開くと、片方の変更がもう片方にすぐ反映されます。

| ページ | ファイル | 開き方 |
|---|---|---|
| 管理者ページ（店長専用・すべてここで完結） | `admin.html` | 管理者のPIN（見本は 0000）で開く |
| 従業員ページ（スマホ用） | `staff.html` | 名前と本人のPINでログイン |
| 入口 | `index.html` | 管理者ページへ移動するだけ |

## 2. 「本人のデータしか届かない」仕組み

- 従業員ページ（`js/staff.js`）は、データ置き場（`App.Store`）を**直接さわりません**。かならず `js/api.js` の `App.StaffAPI` を通します。
- 窓口が返すもの：本人のプロフィール（時給を含む）、本人のシフト・希望・打刻、本人の確定した給与明細、お知らせ、同僚の**氏名だけ**。
- リアクションは従業員には**人数だけ**、管理者には名前つきで見せます。
- **試作版の限界**：同じ端末のブラウザに全データがあるため、本当の意味で守られてはいません。本番ではサーバー側で本人確認をしてから本人分だけを送ります（形式 B・C）。管理者PINも試作版では簡易なものです。

## 2-2. 法令に関わる表示と動き

| 法令 | 画面での扱い |
|---|---|
| 労働基準法32条（1日8時間・週40時間） | 両方を超えた分を時間外として計算（週の始まりは設定） |
| 同34条（休憩） | 6時間超45分・8時間超60分に足りない日を表示。修正時は保存させない |
| 同36条（36協定） | 協定なしの時間外、月・年の上限超え・8割超えを表示 |
| 同37条（割増賃金） | 時間外25%、月60時間超50%、深夜25%。下限より低い率は保存させない |
| 同60・61条（年少者） | 18歳未満の時間外・深夜（22時以降のシフト予定を含む）を表示 |
| 同107条（労働者名簿） | 法定項目に印、未記入を表示。退職者は削除せず「退職」で残す |
| 同108条（賃金台帳） | 専用タブ |
| 同109条（記録の保存） | 打刻・確定給与・退職者を消さない作り。試作版はバックアップが必要 |
| 労働安全衛生法66条の8の3（労働時間の把握） | 本人の打刻。管理者の修正・手入力・削除は理由つきで記録し、記録は消せない |
| 最低賃金法4条 | 最低賃金より低い時給は保存させない |
| 所得税法231条（給与支払明細書） | 必要な項目を明細に表示。メールでの交付は本人が同意した人だけ |
| 個人情報保護法 | 従業員ページには本人のデータと同僚の氏名だけ。利用目的をページに表示 |

まだ対応していないもの：労働条件通知書（15条）、年次有給休暇と管理簿（39条）、休日労働の割増（35%）、年末調整、住民税、社会保険の標準報酬月額。

**数値の確認が必要なもの**（初期値には「要確認」の印があり、法令チェックに出ます）：源泉所得税の税額表（令和8年分から改正）、雇用保険料率（毎年4月）、地域別最低賃金（毎年10月ごろ）。

## 2-3. メール配信（月1回・本人分だけ）

- 内容：給与明細（電子交付に同意した人だけ）、その月の勤怠（打刻）、翌月のシフト。
- 1人ずつ別々のメールで送り、ほかの人のアドレスや内容は入れない。
- 送信のタイミング：**未設定（あとで指定）**。給料日・毎月決まった日・給与確定時から選べるようにしてあります。
- 試作版では送信しません。本番では、サーバー（例：Google Apps Script のトリガー）が決まった日に送ります。

## 3. 作り方の形式（3段階）

| | A. 試作版（今回） | B. スプレッドシート版 | C. 本格版 |
|---|---|---|---|
| 仕組み | HTML＋JavaScript だけ | Googleスプレッドシート＋Google Apps Script | Supabase（または Firebase）＋スマホ用Webアプリ（PWA） |
| データ | その端末のブラウザ | スプレッドシート（店長のGoogleアカウント） | クラウドのデータベース |
| 従業員のスマホから使う | ×（同じ端末だけ） | ○ | ○ |
| 本人のデータだけ届く | 画面上だけ | ○（Apps Script で本人分だけ返す） | ◎（データベースの行単位の権限 RLS） |
| ログイン | 名前＋PIN（見本） | 名前＋PIN、またはGoogleログイン | メール・LINEログインなど |
| 費用 | 0円 | 0円（Googleの無料枠） | 小規模なら0円〜月数千円 |
| 作る難しさ | ★ | ★★ | ★★★ |
| 向いている店 | 画面を確かめたい段階 | 従業員10人くらいまで | 複数店舗・長く使う |

**おすすめの進め方**：A で画面と計算を決める（今ここ） → B で実際に1か月使ってみる → 困るところが出たら C に作り替える。
画面のファイル（`admin*.js`、`staff.js`）はそのまま使い回し、`core.js` の `App.Store` と `api.js` だけを B・C 用に差し替える設計にしています。メールの自動送信も B・C で実際に動くようになります。

## 6. 給与計算のルール（試作版）

- 締め：月末、支給：翌月25日（設定で変更可）
- 基本給＝時給×実働時間（出勤〜退勤−休憩、分単位）。円未満は四捨五入
- 時間外：1日8時間・1週40時間を超えた分に時給×0.25、月60時間を超えた分は×0.5を加算（割増率は設定で変更可）
- 深夜：22時〜翌5時の分に時給×0.25を加算
- 通勤手当：1日あたりの金額×出勤日数（非課税として扱う）
- 雇用保険料：総支給額×料率（初期値 0.0055）。50銭以下切り捨て・50銭超切り上げ
- 社会保険料：名簿に月額を手入力（標準報酬月額の自動計算は未対応）
- 所得税：甲欄は「電算機計算の特例」の式、乙欄は10万5千円未満を3.063%

### 必ず確認が必要なこと

- **税額の数値は令和2〜7年分の電算機計算の特例を初期値にしています。** 税制改正により令和8年分（2026年1月以降の支払）の税額表は変わっています。
  本番で使う前に、国税庁の最新の「源泉徴収税額表」で数値を確認し、「設定・データ」タブで更新してください。
- 雇用保険料率は年度ごとに変わります（毎年4月）。
- 乙欄で10万5千円以上、年末調整、住民税の特別徴収、社会保険の標準報酬月額は試作版では計算していません。
- 給与・税の計算は、実際に支払う前に税理士・社労士に確認してもらうことをおすすめします。
