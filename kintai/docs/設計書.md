# ミセカン 設計書（試作版 v0.1）

店長1人が使う「管理画面」と、従業員が自分のスマホで使う「従業員アプリ」をひとつにまとめた店舗管理ツールです。
この試作版は、画面と計算の流れを確かめるためのものです。実際の店で使うには、下の「作り方の形式」の B か C に進めてください。

## 2. 「本人のデータしか届かない」仕組み

- 従業員アプリ（`js/staff.js`）は、データ置き場（`App.Store`）を**直接さわりません**。
- かならず `js/api.js` の `App.StaffAPI` を通します。ここが「本人確認をして、本人の分だけを返す窓口」です。
  - 返すもの：本人のプロフィール（時給を含む）、本人のシフト・希望・打刻、本人の確定した給与明細、お知らせ
  - お知らせのリアクションは**人数だけ**返し、誰が押したかは従業員には返しません（管理画面では名前つきで見えます）
- **試作版の限界**：今は管理画面と同じブラウザの中で動いているので、技術的には全データが同じ端末にあります。
  本番では、この窓口と同じ形の API を**サーバー側**に作り、ログイン情報で本人を確かめてから本人分だけを送ります（形式 B・C）。

## 3. 作り方の形式（3段階）

| | A. 試作版（今回） | B. スプレッドシート版 | C. 本格版 |
|---|---|---|---|
| 仕組み | HTML＋JavaScript だけ | Googleスプレッドシート＋Google Apps Script | Supabase（または Firebase）＋スマホ用Webアプリ（PWA） |
| データ | その端末のブラウザ | スプレッドシート（店長のGoogleアカウント） | クラウドのデータベース |
| 従業員のスマホから使う | ×（同じ端末だけ） | ○ | ○ |
| 本人のデータだけ届く | 画面上だけ | ○（Apps Script で本人分だけ返す） | ◎（データベースの行単位の権限 RLS） |
| ログイン | 名前＋PIN（見本） | 名前＋PIN、またはGoogleログイン | メール・LINEログインなど |
| 費用 | 0円 | 0円（Googleの無料枠） | 小規模なら0円〜月数千円 |
| 作る難しさ | ★ | ★★ | ★★★ |
| 向いている店 | 画面を確かめたい段階 | 従業員10人くらいまで | 複数店舗・長く使う |

**おすすめの進め方**：A で画面と計算を決める → B で実際に1か月使ってみる → 困るところが出たら C に作り替える。
画面のファイル（`admin*.js`、`staff.js`）はそのまま使い回し、`core.js` の `App.Store` と `api.js` だけを B・C 用に差し替える設計にしています。

## 4. ファイルの分け方（1ファイル＝1つの部品）

```
kintai/
  index.html          画面の枠（上のバー、管理画面、従業員アプリ）と読み込む順番
  css/app.css         見た目（ライト・ダーク両対応）
  js/core.js          日付・時刻・金額の道具、データの保存、確認ダイアログ、グラフ
  js/payroll.js       給与と源泉所得税の計算（画面を持たない）
  js/seed.js          見本データ
  js/api.js           従業員アプリ用の窓口（本人分だけ返す）
  js/admin.js         管理画面のタブの仕組み、ホーム、掲示板、名簿、設定
  js/admin-shift.js   シフト、勤怠・打刻
  js/admin-pay.js     給与計算、給与明細、源泉徴収
  js/admin-sales.js   売上、購買履歴・ランキング
  js/staff.js         従業員アプリ
  js/main.js          起動と画面の切り替え（#app で従業員アプリ）
```

タブを増やすときは、新しいファイルで `App.Admin.register({ id, label, group, lead, render(main) })` を呼び、`index.html` に1行足すだけです。

## 6. 給与計算のルール（試作版）

- 締め：月末、支給：翌月25日（設定で変更可）
- 基本給＝時給×実働時間（出勤〜退勤−休憩、分単位）。円未満は四捨五入
- 残業：1日8時間を超えた分に時給×0.25を加算（割増率は設定で変更可）
- 深夜：22時〜翌5時の分に時給×0.25を加算
- 通勤手当：1日あたりの金額×出勤日数（非課税として扱う）
- 雇用保険料：総支給額×料率（初期値 0.0055）。50銭以下切り捨て・50銭超切り上げ
- 社会保険料：名簿に月額を手入力（標準報酬月額の自動計算は未対応）
- 所得税：甲欄は「電算機計算の特例」の式、乙欄は10万5千円未満を3.063%

### 必ず確認が必要なこと

- **税額の数値は令和2〜7年分の電算機計算の特例を初期値にしています。** 税制改正により令和8年分（2026年1月以降の支払）の税額表は変わっています。
  本番で使う前に、国税庁の最新の「源泉徴収税額表」で数値を確認し、「設定・データ」タブで更新してください。
- 雇用保険料率は年度ごとに変わります（毎年4月）。
- 乙欄で10万5千円以上、年末調整、住民税の特別徴収、社会保険の標準報酬月額は試作版では計算していません。
- 給与・税の計算は、実際に支払う前に税理士・社労士に確認してもらうことをおすすめします。
