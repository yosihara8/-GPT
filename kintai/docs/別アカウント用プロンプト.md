# ミセカン（シフト・勤怠・給与・売上の店舗管理）別のClaudeアカウントで作るための正式プロンプト

対象：試作版 v0.3（管理者ページ＋従業員ページ）
作成日：2026年11月20日

---

## はじめに：2つの方法があります

| | 方法A：ファイルを渡す | 方法B：仕様書から作る |
|---|---|---|
| できあがり | **全く同じ**（コードがそのまま同じ） | 機能・画面・計算は同じ。細かい見た目や文の言い回しが少し変わることがある |
| 必要なもの | `dist/misekan-admin.html` と `dist/misekan-staff.html` の2ファイル | このプロンプトだけ |
| 手間 | 1回 | 8回に分けて頼む |
| おすすめ | **「全く同じ」が必要ならこちら** | ファイルを渡せないとき・作り直したいとき |

約2,500行あるプログラムを、文章だけで1文字も違わずに再現させることはできません。「全く同じ」にしたいときは、方法Aを使ってください。

---

## 方法A：ファイルを渡して作ってもらう（全く同じ）

### 手順
1. 次の2つのファイルを用意します（GitHubのブランチ `claude/shift-schedule-creation-h5gaqa` の `kintai/dist/` にあります）。
   - `misekan-admin.html`（管理者ページ。CSSとJavaScriptを全部中に入れた1枚）
   - `misekan-staff.html`（従業員ページ。同じく1枚）
2. 別のアカウントのClaudeに、2つのファイルを添付して、下のプロンプトを貼ります。

### プロンプトA（そのまま貼る）


### うまくいかないとき
- 「ファイルが大きすぎる」と言われたら：パソコンのブラウザ（Chrome など）で2つのファイルを**同じフォルダに入れてダブルクリック**すれば、そのまま動きます。Claudeを使わなくても確認できます。
- 2つのページの行き来は、2つのファイルが同じフォルダにあるときだけ動きます。

```
# ミセカン 仕様書（試作版 v0.3）

## 0. 全体のルール
- HTML・CSS・JavaScript だけで作る。サーバー、データベース、ログイン基盤、外部ライブラリ、ビルドツールは使わない（フォントだけ Google Fonts から読み込む）。
- 画面の文字はすべて日本語。英語の言葉（PIN、OK、ID など）は使わない（「暗証番号」「はい」など）。
- データはブラウザの localStorage のキー 'misekan.v2' に1つのJSONとして保存する。保存できない環境でも画面は動くように try/catch で守る。
- ページは2つ：admin.html（管理者ページ）と staff.html（従業員ページ）。index.html は admin.html へ移動するだけ。
- 同じブラウザで2つのページを開いているとき、片方で保存したら window の storage イベントでもう片方の表示を更新する（入力中・確認画面を開いているときは更新しない）。
- ブラウザの alert / confirm / prompt と window.print は使わない。確認は画面内の小さな窓（モーダル）で行う。ファイルのダウンロードも使わない（バックアップは文字をコピーする方式）。
- 従業員ページは App.Store（データ置き場）を直接さわらず、本人の分だけを返す窓口 App.StaffAPI だけを使う。
- スマホ幅（390px）でも画面全体が横にはみ出さない。横に長い表だけ、その表の中で横スクロールする。
- すべてのグローバルは window.App の下にまとめ、各ファイルは (function(){ ... })(); で包む。

## 3. 計算のルール（payroll.js）
- 1日：実働＝退勤−出勤−休憩（退勤が出勤以前なら翌日扱いで+24時間）。深夜＝22:00〜翌5:00と重なる分（実働を上限）。1日8時間超＝実働−480分（0未満は0）。
- 週40時間：settings.weekStart の曜日から週を数え、各日の「8時間以内の部分」を足していき、40時間を超えた分をその日の時間外にする。月の初日がある週は前月の日から数え始める。時間外＝1日8時間超＋週40時間超。
- 休憩（労働基準法34条）：実働が6時間超なら45分、8時間超なら60分が必要。足りない分＝必要−休憩。
- 月の給与：基本給＝時給×実働/60、時間外手当＝時給×(otRate−1)×(時間外のうち60時間まで)/60＋時給×(ot60Rate−1)×(60時間を超えた分)/60、深夜手当＝時給×(nightRate−1)×深夜/60（どれも円未満四捨五入）。
  通勤手当＝1日の交通費×出勤日数（非課税）。総支給＝合計。課税支給＝総支給−通勤手当。
  雇用保険料＝加入者のみ 総支給×empInsRate（小数部分が0.5以下は切り捨て、0.5を超えたら切り上げ）。社会保険料＝名簿の月額。
  所得税：甲欄は「電算機計算の特例」：A＝課税支給−雇用保険料−社会保険料。A<88,000なら0円。給与所得控除（月額）を表で求め、B＝A−給与所得控除−基礎控除40,000−扶養1人31,667×人数、税＝B×税率−控除 を10円未満四捨五入。
    給与所得控除の表：A≤135,416→45,834／≤149,999→A×40%−8,333／≤299,999→A×30%+6,667／≤549,999→A×20%+36,667／≤708,330→A×10%+91,667／それ以上→162,500（率の計算は切り上げ）
    税率の表：B≤162,500→5.105%／≤275,000→10.21%−8,296／≤579,166→20.42%−36,374／≤750,000→23.483%−54,113／≤1,500,000→33.693%−130,688／≤3,333,333→40.84%−237,893／それ以上→45.945%−408,061
    この数値は「令和2〜7年分の電算機計算の特例（令和8年分は要確認）」と画面に表示する。表の上限なしは JSON では null で保存し、計算時に無限大として扱う。
  乙欄：A×3.063%（切り捨て）。A≥105,000なら「乙欄で10万5千円以上は税額表で確認が必要です（試作では一律の率で概算）」と注記。
  差引支給＝総支給−（雇用保険料＋社会保険料＋所得税）。
  結果に入れる項目：ym, staffId, name, gender, wage, days, periodStart, periodEnd, payDate, workMin, otMin, ot60Min, nightMin, base, otPay, nightPay, transport, gross, taxable, empIns, social, tax, taxNote, deductions, net, openDays（退勤のない日数）, storeName
- 支給日：月末締め・翌月の payDay 日（その月にない日なら月末）。
- 年間の給与所得控除（源泉徴収票の概算）：≤190万→min(支払額,65万)／≤360万→30%+8万／≤660万→20%+44万／≤850万→10%+110万／それ以上195万。

### 4-1 ホーム
4枚の数字カード（それぞれ下に出どころのリンク）：昨日の売上（未入力なら「まだ入力されていません」）／今月の売上（1日〜昨日）と前年同期比（前年同月の同じ日まで）／今月の人件費（見込み・総支給の合計）と人件費率（目標以下なら緑）／今日の出勤人数・出勤中の人数・未承認の希望数。
その下に「法令チェック」の要約（すぐ対応と確認を最大3件）、「今日の出勤状況」（名前・シフト・出勤・退勤・状態：退勤済み／休憩中／出勤中／出勤中（遅刻）／未出勤／出勤前）、「掲示板の既読」（新しい4件の既読数のメーター）、「月別の売上」（直近12か月の縦棒グラフ）。

### 4-2 データの入力と流れ
表：データ／入力する人／入力する場所／使われる画面／件数／最新／ボタン（「入力する」または「開く」、従業員が入力するものは「従業員ページ」）。行は13種類：売上、商品ごとの販売記録、商品マスタ、従業員、シフト希望、シフト（確定）、打刻、給与（確定）、お知らせ、既読・リアクション、設定、メール配信の設定、修正の記録。
```
