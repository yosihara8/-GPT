# AIメルマガ 自動配信の手順書

毎週金曜に、AIが最新情報を調べて原稿を作り、夕方にスプレッドシートのリストへ配信する仕組みです。

## 毎週の動き

| 時刻（金曜） | 自動で行うこと | あなたがすること |
|---|---|---|
| 12時台 | AIが今週のAIニュースを調べて原稿を作り、**確認用アドレスに下書きを送る** | 下書きを読み、問題なければ「原稿」シートの状態を **「承認」** にする（直したい所はシートで直接直せます） |
| 17時台 | 「承認」済みの原稿を、配信対象の人へ **1人ずつ宛名付きで** 送る | なし（送信結果のメールが届きます） |
| いつでも | 配信停止リンクが押されたら、リストの「配信状態」が自動で **「停止」** になる | なし |

- 承認し忘れた週は送信されず、「未承認のため送っていません」というお知らせが届きます。
- 慣れてきたら、「設定」シートの **確認モードをOFF** にすると完全自動になります。
- 開封数は「原稿」シートのH列で目安を確認できます。Apple製品のメールアプリなどでは開いていなくても数えられることがあるため、あくまで参考値です。

## 準備するもの

1. **送信に使うGoogleアカウント**（法人のGoogle Workspaceを推奨）
   - Apps Scriptからの送信上限は、個人Gmailで **1日100通**、Google Workspaceで **1日1,500通** です。リストが増える予定なので、法人アカウントで動かすのがおすすめです。
2. **Claude APIキー**（ https://console.anthropic.com で取得し、クレジットを少額チャージ）
   - 目安：1号あたり数十円〜100円程度（検索回数と文章量によって変わります）

## 設定手順（初回だけ・30分ほど）

### 1. スプレッドシートにスクリプトを入れる
1. アドレスリストのスプレッドシートを開く
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている `コード.gs` の中身を全部消し、`Code.gs` の内容を貼り付けて保存
4. 左の歯車（プロジェクトの設定）→「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック → `appsscript.json` を、同じ名前のファイルの内容に置き換えて保存

### 2. 初期設定を実行
1. 上部の関数の選択欄で **`setup`** を選んで「実行」
2. 権限の確認画面が出たら許可（「このアプリは確認されていません」と出たら「詳細」→「移動」）
3. 「配信リスト」「設定」「原稿」「開封ログ」のシートができます

### 3. APIキーを登録
歯車（プロジェクトの設定）→ 一番下の **スクリプト プロパティ** → 追加
- プロパティ：`ANTHROPIC_API_KEY`
- 値：取得したAPIキー

### 4. 配信停止・開封記録の受付を公開
1. 右上の **デプロイ → 新しいデプロイ** → 種類で「ウェブアプリ」を選ぶ
2. 次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
3. デプロイ後に表示される **ウェブアプリのURL** をコピー
4. 手順3と同じ「スクリプト プロパティ」に追加
   - プロパティ：`WEBAPP_URL`
   - 値：コピーしたURL

### 5. 「設定」シートを埋める
会社名・住所・お問い合わせ先は **法律上必須** です。サービス・セミナー・コンサルの案内文とURLもここに書きます。空欄の項目はメールに表示されません。

### 6. 「配信リスト」シートを整える
今のアドレスリストを貼り付け、次の2列を必ず埋めてください。

| 列 | 入れる値 |
|---|---|
| 配信状態 | `配信中` または `停止` |
| 同意区分 | `同意あり`／`名刺交換`／`取引先`／`不明` |

**`不明` の人には送信されません**（次の章を参照）。

### 7. 試し送信
1. 「設定」の確認用アドレスに自分のアドレスを入れる
2. 関数 **`createDraft`** を手動で実行 → 1〜3分で下書きが届きます
3. 配信リストを自分のアドレス1件だけにして（他は一時的に `停止`）、原稿を「承認」にし、**`sendNewsletter`** を実行
4. 届いたメールで、見た目・配信停止リンク（押すとリストが「停止」になる）を確認
5. 確認できたら配信リストを元に戻せば準備完了です。あとは毎週金曜に自動で動きます

> 時刻を変えたいときは「設定」シートを書き換え、関数 `installTriggers` を実行してください。

## 同意について（特定電子メール法）・最重要

宣伝を目的としたメールは、原則として **受信者の事前の同意が必要** です。次の場合は例外として同意なしで送れます（配信停止の方法と送信者の表示は必要）。

| 同意区分 | 例 |
|---|---|
| 同意あり | 申込フォームやセミナー受付で「メルマガを受け取る」に同意した |
| 名刺交換 | 名刺など **書面で** メールアドレスを受け取った |
| 取引先 | 取引のある相手（お客様・取引先） |

**同意が不明な人への対応**
- 「メルマガを送ってよいですか？」と確認するメールを送ることも、原則として規制の対象になります。メールで一斉に確認するのは避けてください。
- 代わりに、**登録フォーム（Googleフォームなど）** をホームページ・SNS・セミナー会場・名刺に載せ、そこから登録してもらうのが安全です。登録した人は「同意あり」、同意取得日と方法をシートに記録してください（同意の記録は保存が義務づけられています）。
- 迷う場合は `不明` のままにしておけば送信されません。

正式な内容は、総務省・消費者庁の「特定電子メールの送信等に関するガイドライン」をご確認ください。

## よくある調整

| やりたいこと | 方法 |
|---|---|
| 原稿の雰囲気や構成を変えたい | `Code.gs` の `generateWithClaude_` 内の文章（読者・トーン・構成）を書き換える |
| 今週は送らない | 原稿シートの状態を `見送り` にする |
| 完全自動にしたい | 設定シートの確認モードを `OFF` |
| 配信数が数百件を超えた | 配信リストをCSVで書き出し、Brevoなどの配信サービスへ移行（原稿づくりはこの仕組みをそのまま使えます） |
