このファイルは、オーナーと決めた仕様を崩さないためのメモです。修正のたびに必ず確認してください。

## 名前
- サイト名は **「佐賀観光マップ」**。画面・メール・規約で他の名前（SagaMap、佐賀おでかけマップ等）を表示しない。
  - `OPERATOR.serviceName`（src/lib/config.ts）が正。コード内の識別子・Cookie 名・ドメイン（sagamap）は変えない。

## 本番のアドレス
- 正式なアドレスは **https://www.saga-kanko-map.com**（Vercel で購入。saga-kanko-map.com は www へ転送）。
- Vercel の環境変数 `NEXT_PUBLIC_APP_URL` と `NEXTAUTH_URL` に同じアドレスを設定済み。メールの送信元は `noreply@saga-kanko-map.com`。

## お客さまの画面（地図はトップ `/` の 1 画面。マイページ `/dashboard/customer` はお知らせ・お気に入り・利用履歴・設定）
- 未登録の方には最初に会員登録画面を出す（middleware で `/` と `/shops/*` は未ログインなら `/register/customer` へ）。ログイン・登録後は `/` へ。
- ログイン後の画面では会員登録の勧誘（「無料の会員登録で〜」等）を出さない。
- 地図の画面（`src/app/page.tsx`）は 1 ページで完結させる:
  - スマホは地図を上部に固定（sticky、42dvh）。地図の上に検索欄（店名・業種・紹介文・住所）と業種の切り替え。パソコンは左に一覧、右に地図。
  - 地図のピン／札／PR／一覧のカードをタップ → 同じページでお店の内容（ShopSheet：写真・経路／電話／保存／共有の4ボタン・使えるクーポン・営業時間・定休日・住所（Googleマップ）・電話）を表示し、その位置まで自動で移動。地図もそのお店に移動。
  - 「経路」で同じ地図に経路を表示。表示中に別のお店を選ぶと、そのお店への経路に切り替える。観光スポットのタップでも経路。マイページの「お気に入りを巡るルート」は `/?route=fav`。
  - 下に横スライドの一覧（Carousel）：近くのクーポン・あなたへのおすすめ・近くのお店（おすすめと重複させない）・PR・お店からのお知らせ・観光スポット。
  - 古いリンク `/dashboard/customer?shop=ID` は `/?shop=ID` に転送。`/dashboard/customer/history` はマイページの #history に転送。
- クーポン配信中のお店は赤いピンと割引率の札（例「10%OFF」）を常に表示。札が重なるときは 1 つにまとめて「+2」（declutter）。お客さまの地図に凡例・「人の流れ」は出さない（事業主向け）。
- クーポンを使う: 「使う」→ 確認（誤タップ防止）→ 画面いっぱいの「利用済」チケット（日時の印・動く時計）を店員に見せる（CouponUse）。
- PR 広告をタップしたら、広告の内容（画像・見出し・本文・お店の名前）をお店の内容の上に表示。表示・タップは ad_events に記録（同じ人の重複は数えない。事業主・運営者の閲覧は数えない）。
- クーポンに写真があれば、クーポンの表示に写真を出す（CouponRow）。
- 専門用語（地理空間・GEOSPATIAL 等）は画面に出さない。タップ数を減らすことを最優先にする。

## 事業主の画面（深緑）
- ロゴ（ホーム）は事業主ダッシュボードに戻る（お客さまの地図に飛ばさない）。
- ダッシュボード: 現在のプランは 1 行に短縮（タップで全文）。有料機能のボタンに「有料プラン中」。いま配信中のクーポン・広告を一覧表示。
- 広告出稿: 画像（任意）あり。出稿後は完了画面 →「事業主ホームに戻る」。停止ボタンは置かない。出稿した広告はタップで内容と統計（表示・タップ・見た会員数）を表示し、「内容を修正する」で修正できる（出稿回数は使わず、掲載期間も変えない）。
- クーポン発行: 「クーポンの使い方」の説明欄、写真（任意）、各クーポンに削除ボタン（削除は deleted_at を入れる論理削除。利用回数の記録は残す）。
- ダッシュボードの「いま配信中のクーポン・広告」はタップで内容（写真・本文）を画面を変えずに表示。
- 解約: Stripe のカスタマーポータルで「請求期間の終了時」に解約。支払い済みの最終日（business_owners.plan_ends_at）までは有料プランのまま使え、ダッシュボードと /upgrade に「〇月〇日まで有料プランを使えます」と表示。最終日に subscription.deleted で無料に戻る。
- Stripe の Managed Payments は使わない（テスト・本番とも既定で無効にする）。
- 紹介プログラム: 説明の重要部分は色付き文字。QR コードの下に「無料会員登録」、画像で保存できる。

## 見た目
- デザインは「観光の色」のデザイン完成版（オーナー承認済み）。絵文字は使わず lucide のアイコン。
- 色: 藍 #1E3A6E・朝焼け #EE6A3A・柿右衛門 #C43D2B（クーポン）・嬉野茶 #5F7F35・黄金 #E3B04B・白磁 #FAF6EF（背景）・墨 #1B1F2A（文字。slate を墨ベースに置き換え済み）。
- 画面の種類ごとの色: お客さま＝藍 / 事業主＝深緑＋黄金 / 管理者＝紫＋墨のヘッダー（ThemeScope と globals.css の CSS 変数）。
- 文字: 大見出し（h1）とお店の名前は明朝（Shippori Mincho B1）、本文は Zen Kaku Gothic New、数字は Outfit（`.num`）。
- いちばん押してほしいボタン（会員登録・経路を表示・クーポン発行・広告出稿）は朝焼け色の `btn-accent`。その他は `btn-primary`。
- ブランドマークはピンの中に熱気球（Logo.tsx、favicon は src/app/icon.svg）。
- 会員登録・ログインの上部に佐賀の一枚絵（public/art/panorama.svg、SagaHero）。濃い帯には有田焼の唐草（`.karakusa`）。
- クーポンは切り取り線つきのチケット（CouponRow）。
- 事業主はパソコンで左メニュー、スマホで画面下のタブ（BusinessNav：ホーム・クーポン・広告・紹介・プラン）。お客さま側は 1 ページ完結のため下タブは付けない。
- 事業主は店舗情報で「営業時間」「定休日」を入力でき、お客さまのお店の内容に表示される。

## 変更時の注意
- 自動処理（毎週金曜メール、毎晩の掲載チェック、毎月のバックアップ・帳簿・紹介割引）・決済・DB の設定を壊さない。
