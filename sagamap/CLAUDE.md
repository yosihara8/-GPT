## お客さまの画面（地図はトップ `/` の 1 画面。マイページ `/dashboard/customer` はお知らせ・お気に入り・利用履歴・設定）
- 未登録の方には最初に会員登録画面を出す（middleware で `/` と `/shops/*` は未ログインなら `/register/customer` へ）。ログイン・登録後は `/` へ。
- ログイン後の画面では会員登録の勧誘（「無料の会員登録で〜」等）を出さない。
- 地図の画面（`src/app/page.tsx`）は 1 ページで完結させる:
  - スマホは地図を上部に固定（sticky、42dvh）。地図の上に検索欄（店名・業種・紹介文・住所）と業種の切り替え。パソコンは左に一覧、右に地図。
  - タップの流れ（目的は登録店の来店・売上）:
    1. 一覧のカード・クーポン・PR → すぐに「お店のページ」（DetailSheet。スマホは画面いっぱい、パソコンは左側）。押したクーポン（条件・期限・残り日数・使い方 3 ステップ）や PR（画像・全文・掲載期限）をいちばん上に大きく出し、その下にお店の写真・営業中かどうか・距離・紹介・経路/電話/保存/共有・ほかのクーポン・お店からのお知らせ・営業時間/住所/電話/SNS・小さな地図。下に「〇%OFFを使う」「ここへ行く」を常に固定。
       地図のピン → 地図の下に小さな案内（写真・割引・営業中・距離）→「お店の詳細」「ここへ行く」。
    2. 「ここへ行く／経路」→ お店のページを閉じて地図に経路と帯（徒歩/車・所要時間・ナビを開始（Googleマップ）・お店の情報・クーポン）。電話・クーポンを使う → 確認 → 利用済み画面。
    3. お店のページの下に「このお店の近くのお店」（3km 以内・クーポン配信中を先に）→ はしご・ついで寄りに。
  - お店のページはスマホの「戻る」で閉じる（history.pushState）。押しても反応しない場所を作らない（タップ全経路を Playwright で確認）。
  - 「経路」で同じ地図に経路を表示。観光スポットのタップでも経路。マイページの「お気に入りを巡るルート」は `/?route=fav`。`/?shop=ID` でお店のページを開く。
  - 下に横スライドの一覧（Carousel）：近くのクーポン・PR・あなたへのおすすめ・近くのお店（おすすめと重複させない）・観光スポット。
  - 営業中・まもなく閉店・営業時間外・本日定休日は営業時間/定休日の文字から判断（src/lib/open-status.ts。読めない書き方は出さない）。クーポンは残り 7 日以内なら「あと〇日」。
  - お客さまの行動（経路・ナビ・電話・保存・共有・クーポンを見た）は shop_events に記録し（会員のみ・同じ人の同じ操作は 1 時間に 1 回）、事業主ダッシュボードの「お店に来ようとしたお客さま（直近 30 日）」に出す。
  - 古いリンク `/dashboard/customer?shop=ID` は `/?shop=ID` に転送。`/dashboard/customer/history` はマイページの #history に転送。
- クーポン配信中のお店は赤いピンと割引率の札（例「10%OFF」）を常に表示。札が重なるときは 1 つにまとめて「+2」（declutter）。お客さまの地図に凡例・「人の流れ」は出さない（事業主向け）。
- クーポンを使う: 「使う」→ 確認（誤タップ防止）→ 画面いっぱいの「利用済」チケット（日時の印・動く時計）を店員に見せる（CouponUse）。
- PR 広告をタップしたら、広告の内容（画像・見出し・本文・お店の名前）をお店の内容の上に表示。表示・タップは ad_events に記録（同じ人の重複は数えない。事業主・運営者の閲覧は数えない）。
- クーポンに写真があれば、クーポンの表示に写真を出す（CouponRow）。
- クーポンの種類は制限しない（src/lib/coupon.ts が正）: 「〇%OFF」「〇円引き」「特別価格（通常価格に取り消し線）」「特典（トッピング無料・1品サービス等を自由に書く）」。
  - 表示は種類に合わせる（couponBadge / couponHeadline / couponShort、SQL は BEST_LABEL_SQL 等）。割引率だけを前提にした表示を作らない。
  - 細かい設定: 先着〇名（残り人数を表示）・初めての方限定・何度でも使える（1 人 1 日 1 回）。既定は 1 人 1 回。/api/coupons/[id]/use で判定。
- お店のページにメニュー（menu_items。写真・価格・説明、50 品まで）と設備・サービス（amenities。駐車場・テイクアウト等、config の AMENITIES）を出す。
  - 予約・LINE・ホームページのリンクは有料プランの機能。あればアクションの「予約する」等に出す。
- 地図の上に絞り込み（営業中・クーポンあり・駐車場あり・テイクアウト・子ども連れ歓迎・カード払いOK）。検索か絞り込み中は結果の一覧を出す。
- 写真がないお店は業種ごとの絵（ShopPhoto）を出す。見出しは明朝＋英字の小見出し（COUPON / PICK UP 等）。
- 専門用語（地理空間・GEOSPATIAL 等）は画面に出さない。タップ数を減らすことを最優先にする。

- ログイン後のお客さまは、まず地図の画面（`/`）へ（お店・クーポンを指したリンクのときだけその画面）。初回は使い方ガイド（GuideTour：画面を暗くして順に照らす。端末ごとに 1 回、「使い方」でもう一度）。
- お知らせ（NotificationList・NoticeSheet・useNotifications）: 見たら自動で既読（既読ボタンは置かない）。見ている間だけ NEW、読んだものは「以前のお知らせ」にたたむ。× で削除。地図の画面ではベル／案内から下に開き、押すとその場でお店・クーポンを開く。読んだお知らせは 30 日、全部 90 日で自動削除。
- お店のページは上に目次（写真・概要／クーポン／メニュー／営業時間／支払い・アクセス／近くのお店）。今いる場所に色を付ける。
- 地図は国土地理院の標準地図（カラー。色を落とすフィルターは掛けない。航空写真に切り替え可）＋しずく形のピン＋右側の割引の札。Google 地図のときは他社の店名などを減らす。
- 開いているページ・タブには必ず色を付ける（ヘッダーの「地図／マイページ」、事業主のメニュー、マイページの下のメニュー、管理画面のタブ）。

## 事業主の画面（深緑）
- ロゴ（ホーム）は事業主ダッシュボードに戻る（お客さまの地図に飛ばさない）。
- ダッシュボード: 現在のプランは 1 行に短縮（タップで全文）。有料機能のボタンに「有料プラン中」。いま配信中のクーポン・広告を一覧表示。
- 広告出稿: 画像（任意）あり。出稿後は完了画面 →「事業主ホームに戻る」。停止ボタンは置かない。出稿した広告はタップで内容と効果（見た人・タップした人・お店に行こうとした人）を表示し、「内容を修正する」で修正できる（出稿回数は使わず、掲載期間も変えない）。
- クーポン発行: 「クーポンの使い方」の説明欄、写真（任意）、各クーポンに削除ボタン（削除は deleted_at を入れる論理削除。利用回数の記録は残す）。
- ダッシュボードの「いま配信中のクーポン・広告」はタップで内容（写真・本文）を画面を変えずに表示。
- 解約: Stripe のカスタマーポータルで「請求期間の終了時」に解約。支払い済みの最終日（business_owners.plan_ends_at）までは有料プランのまま使え、ダッシュボードと /upgrade に「〇月〇日まで有料プランを使えます」と表示。最終日に subscription.deleted で無料に戻る。
- Stripe の Managed Payments は使わない（テスト・本番とも既定で無効にする）。
- 広告の効果（AdStats）は人数で出す：見た人（表示 〇回）⊇ タップした人 ⊇ お店に行こうとした人（タップ後 14 日以内に道案内・電話・クーポン利用）。地図は会員専用なので「会員」とは書かない。「数字の見方」を必ず添える。
- 特別招待（business_owners.complimentary）: リンクは管理者だけが発行（/admin の「特別招待」）。人数無制限・発行から 3 日間有効（invite_codes.max_uses は NULL）。登録した事業主は有料プランの機能を期限なし・0 円で使える。
  - /upgrade はプランをタッチで選ぶ（radiogroup）。特別招待の方には「特別招待プラン・無料プラン・有料プラン」の 3 つ、それ以外は 2 つ。
  - 特別招待プランをやめる操作は取り消せない（戻れない）。赤い注意枠＋確認のチェック＋確認ダイアログを必ず通す。無料へは POST /api/billing/leave-special、有料へは POST /api/billing { leaveSpecial: true }（お支払い完了の Webhook で complimentary=false。それまでは特別招待のまま）。special_ended_at に終了日時。
- 紹介プログラム: 説明の重要部分は色付き文字。QR コードの下に「無料会員登録」、画像で保存できる。

- ダッシュボードの「お店のページの充実度」（ProfileScore）で、足りない情報（写真・紹介文・営業カレンダー・支払い方法・メニュー・クーポン等）へ 1 タップで案内する。

- レジ横 QR ポスター（/dashboard/business/poster）: A4・A5 で印刷。QR は `/p/店舗ID`（読み取りを shop_events の qr_scan に記録。会員はそのお店のページへ、未登録は紹介元をそのお店にして登録 → お店のページ）。
- 月次レポート（src/lib/owner-report.ts・/dashboard/business/report）: 毎月 1 日に先月分をメール（cron daily の ownerReport）。お店のページを見た回数・経路・電話・保存・クーポン・QR・広告と先月比、充実度、次にやること。report_enabled で停止できる。

## 運営者（管理者）
- 管理画面は独立：専用のログイン（/admin/login → /api/admin/auth/login。Cookie は `__Host-sagamap-admin`、12 時間、SameSite=Strict）。お客さま・事業主のログイン（NextAuth）では運営者に入れない。両方同時にログインしていても干渉しない。
- 管理画面では公開サイトのヘッダー・フッターを出さない（SiteChrome / admin/layout.tsx の専用ヘッダー）。
- パスワードを忘れたら /admin/forgot（運営者のメールにだけ再設定リンク。二段階認証は解除しない）。
- メールもスマホも使えないときの緊急用：Vercel の環境変数 ADMIN_RECOVERY_PASSWORD（12 文字以上。ADMIN_RECOVERY_EMAIL も可）を入れて再デプロイ → 1 回だけ反映し二段階認証も解除。反映後は環境変数を消す。
- 運営者はオーナー 1 人だけ。追加できる画面・API を作らない（DB の一意インデックスでも 1 人に制限）。
- お客さま・事業主の画面に管理画面へのリンクを置かない。

## 本番前の公開制限（ベーシック認証）
- Vercel の環境変数 `BASIC_AUTH_USER` と `BASIC_AUTH_PASSWORD` を両方入れて再デプロイすると、サイト全体（画面・API）に ID とパスワードの入力が必要になる（src/middleware.ts）。消して再デプロイすると一般公開。
- 対象外：`/api/billing/webhook`（Stripe の決済の知らせ）と `/api/cron/*`（Vercel の定期処理。CRON_SECRET で守る）。ここを対象にすると決済・自動処理が壊れる。
- middleware は全パスで動く（matcher は _next/static 等を除く全部）。会員・運営者のログインの確認は needsLogin のパスだけ（以前の matcher と同じ範囲）。

## セキュリティ（弱めない）
- ログインは 15 分にアカウントあたり 10 回・接続元あたり 50 回まで。パスワードは bcrypt。よく使われるパスワード・メールアドレスを含むものは断る（weakPasswordReason）。
- session_version: パスワード変更・再設定・「すべての端末からログアウト」で上げ、古いログイン（盗まれたものも）を無効にする。
- 運営者は二段階認証（認証アプリの 6 桁・src/lib/totp.ts。同じ数字の再使用不可）とログイン通知メール。
- Google ログインで、メール未確認のままパスワード登録されていたアカウントは、パスワードを消して本人のものにする（先回り乗っ取り対策）。
- ログイン後の移動先は自分のサイト内だけ（`//`・`\` を含む URL は使わない）。
- 公開してよい一覧・写真だけ CDN キャッシュ（next.config の no-store の例外）。ログインで内容が変わる API はキャッシュさせない。
- DB はアプリから Neon の接続プール（-pooler）を使う（db.ts）。

- お支払い方法（PaymentFieldset・src/lib/payment.ts・config の PAYMENT_GROUPS）: クレジットカード・バーコード決済・交通系IC・電子マネーごとに「使える（どれか選ぶ）／使えない」。

  - 未登録の人がそのリンクを開くと `/register/customer?next=…` → 登録・ログイン後にそのお店のページを開く。

## デザインの決まり（統一感を崩さない）
- 画面の見出し：事業主は BizPage（深緑の帯・英字の小見出し・明朝の h1・説明）。お客さまのマイページは藍の帯。会員登録・ログインは SagaHero（佐賀の一枚絵）。
- 欄の見出し（カードの外）は SectionTitle（明朝 17px・英字の小見出し・左にアイコン）。カードの中の見出しは h2.font-bold（ゴシック）。
