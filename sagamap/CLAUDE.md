# 佐賀観光マップ — 守るべき仕様（オーナー確認済み）

このファイルは、オーナーと決めた仕様を崩さないためのメモです。修正のたびに必ず確認してください。

## 名前
- サイト名は **「佐賀観光マップ」**。画面・メール・規約で他の名前（SagaMap、佐賀おでかけマップ等）を表示しない。
  - `OPERATOR.serviceName`（src/lib/config.ts）が正。コード内の識別子・Cookie 名・ドメイン（sagamap）は変えない。

## お客さまの画面（トップ `/` とマイページ `/dashboard/customer`）
- 未登録の方には最初に会員登録画面を出す（middleware で `/` と `/shops/*` は未ログインなら `/register/customer` へ）。
- ログイン後の画面では会員登録の勧誘（「無料の会員登録で〜」等）を出さない。
- 1 ページで完結させる（ページを移動させない）:
  - スマホは地図を上部に固定（sticky、45dvh）。下に店舗情報が出ても地図は見えたまま。
  - 地図のピン／「クーポン発行中」ラベル／PR 広告／一覧をタップ → 同じページで店舗情報・店舗写真・クーポンを表示し、その位置まで自動で移動。
  - 「経路を表示」ボタンで同じ地図に経路を表示。表示中に別のお店を選ぶと、そのお店への経路に切り替える。
  - その下に「近くのお店」「おすすめのお店」。タップで同じように開く。
- クーポン配信中のお店は地図上に「クーポン発行中」を常に表示。
- PR 広告をタップしたら、広告の内容（画像・見出し・本文）を店舗情報の上に表示。
- タップ数を減らすことを最優先にする。

## 事業主の画面（青）
- ロゴ（ホーム）は事業主ダッシュボードに戻る（お客さまの地図に飛ばさない）。
- ダッシュボード: 現在のプランは 1 行に短縮（タップで全文）。有料機能のボタンに「有料プラン中」。いま配信中のクーポン・広告を一覧表示。
- 広告出稿: 画像（任意）あり。出稿後は完了画面 →「事業主ホームに戻る」。停止ボタンは置かない。
- 紹介プログラム: 説明の重要部分は色付き文字。QR コードの下に「紹介用リンク」、画像で保存できる。

## 運営者（管理者）
- 運営者はオーナー 1 人だけ。追加できる画面・API を作らない（DB の一意インデックスでも 1 人に制限）。
- お客さま・事業主の画面に管理画面へのリンクを置かない。

## 見た目
- デザインは「地図アプリ型（モダン）」。絵文字は使わず lucide のアイコン。グラデーションは使わない。
- 画面の種類ごとの色: お客さま＝深い緑 / 事業主＝青 / 管理者＝紫＋黒いヘッダー（ThemeScope と globals.css の CSS 変数）。

## 変更時の注意
- 自動処理（毎週金曜メール、毎晩の掲載チェック、毎月のバックアップ・帳簿・紹介割引）・決済・DB の設定を壊さない。
- 変更後は `npx tsc --noEmit`、`npx next lint`、`npx vitest run`、`npx next build` を通す。
- 反映は開発ブランチに push し、`sagamap/` を既定ブランチ（Vercel が本番に使う）にも同期する。
