# 宇宙から見た唐津の海

佐賀県唐津市周辺の海を、人工衛星のデータと地形図を重ねて見るための地図ツールです。
「漁師さんが暮らせる海」を考えるときに、海の自然環境がどうなっているのかを目で見て話し合えるようにします。

## できること

パネル上部のタブで、目的ごとに画面を切り替えます。目的に関係のない項目と地図の層は隠れます。
URL の末尾に `#know`(海を知る)・`#fish`(魚を知る)・`#moba`(藻場を見守る)・`#gomi`(海ごみ)を付けると、その画面から開きます。

| 機能 | 内容 |
|---|---|
| 魚を知る | なぜ魚が減ったのか(公表資料と20年の衛星水温から)と、生き物ごとに「住みやすい水温の月」が昔(2003〜07年)と今(直近5年)で何か月あるかの比較。地図をクリックするとその場所で計算し直す |
| 海底地形図 | GEBCO 2024 の水深から、海図のような色分け・陰影と5〜150mの等深線を作って表示。海をクリックすると水深も出る |
| 藻場を見守る(Isoyake Watch の第1段階) | 同じ場所の写真を2つの年で左右に並べて見比べる。Sentinel-2 衛星写真(2018〜2024年、10m単位)、1974〜78年と最新の航空写真(国土地理院)。島ごとに移動するボタンつき |
| いまの海(リアルタイム) | 潮の流れ(海流+潮汐)を粒子のアニメーションで表示。1日前〜3日先を1時間ごとに再生でき、30分ごとに最新のデータへ自動更新。クリックした地点のいまの流れ・波の高さ・水温も表示 |
| 唐津の調査データ | 佐賀県の観測点(2026年8月の水温と平年差、底層の溶存酸素を測るテレメータへのリンク)、藻場の減少・ウニ漁獲量・ガンガゼ駆除などの調査結果、藻場保全の場所、洋上風力の計画海域の目安 |
| 海ごみ | 漂着ごみが報告されている場所(波戸岬・馬渡島・高島など、回収量と出典つき)と、風上に開けていてごみが押し寄せやすい海岸の表示(冬の北西風、またはいまの風) |
| 陸地 | 国土地理院「地球地図日本」の海岸線・島・市町の境界をデータで同梱。地図画像が読めない時も陸の形がわかる |
| 地形を見る | 海底地形図、航空写真(浅い岩場・藻場の影)、Sentinel-2 衛星写真、海底の起伏(GEBCO)、陸の陰影起伏図 |
| 宇宙から見た海 | 海面水温、水温の平年差、プランクトン(クロロフィル)、その日の衛星写真を日付を選んで重ねる |
| むかしと比べる | 地図を左右に分けて、2つの日付を見比べる(例: 2005年8月と2025年8月) |
| 数値で調べる | 海をクリックすると、その地点の水温・プランクトン量と、生き物ごとの適水温の目安を表示。毎年同じ時期の水温を20年分並べたグラフと傾向(10年あたり何℃)も出せる |
| 地形で見る海の特徴 | 湾・岬・島まわり・砂浜ごとに、すみやすい生き物や起きやすい問題を表示 |
| 海の記憶ピン | 漁師さんや地域の方の「昔は獲れた」「最近ふえた」を地図に残す。ファイルに保存・読み込みができ、ハッカソンで集めて1つにまとめられる |

## 開き方

インターネットにつながったパソコンやスマートフォンのブラウザで `index.html` を開きます。
地図や衛星データはそれぞれの配信元から直接読み込むので、APIキーや登録は不要です。

ローカルで開く場合(ファイルを直接開くとブラウザによっては一部が動かないため):

```sh
cd umi-map
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages で公開すると、URLを共有するだけで地域の方にも見てもらえます。

## テスト

外部のサービス(地図画像・衛星・潮の流れ・風・NOAA)をすべて模擬して、主な機能を確かめます。

```sh
cd umi-map
python3 -m http.server 8765 &
node tests/smoke.cjs   # 外部サービスを模擬したテスト
node tests/live.cjs    # 本物のサーバーにつなぐテスト(インターネットが必要)
```

`umi-map` を変更して GitHub に送ると、GitHub Actions(`.github/workflows/umi-map-live.yml`)が両方のテストを自動で実行します。

## 使っているデータ

| データ | 提供元 | 細かさ |
|---|---|---|
| 潮の流れ・波・いまの水温 | Open-Meteo Marine API(Météo-France SMOC ほか) | 約8km・1時間ごと |
| 観測点の水温と平年値 | 佐賀県玄海水産振興センター「玄海漁場環境情報」令和8年度8月号 | 5地点 |
| 藻場の面積・ウニ漁獲量など | 佐賀県の藻場調査(佐賀新聞)、水産庁 磯焼け対策全国協議会資料、サガテレビ報道、唐津市 | — |
| 海面水温・平年差(MUR SST) | NASA JPL / 表示 NASA GIBS / 数値 NOAA CoastWatch ERDDAP | 約1km・毎日(2002年6月〜) |
| クリック地点の水温 | Open-Meteo Marine(2023年末以降のその日の値)、それより前は下の月平均 | 約5〜50km |
| 20年の水温の変化 | NASA MUR 衛星水温の月平均(NOAA ERDDAP から GitHub Actions で取得し `data/history.js` に同梱) | 約5km間隔・2002年6月〜 |
| クロロフィル(プランクトン) | NOAA-20 VIIRS(2017年12月以降)、NASA MODIS Aqua(それ以前) | 約1km・毎日 |
| その日の衛星写真 | NOAA-20 VIIRS(2018年以降)、NASA MODIS Terra(それ以前) | 約250〜375m・毎日 |
| 海底地形図 | GEBCO 2024 Grid(GitHub Actions で `tools/build_bathy.py` が `data/bathy.js`・`bathy.png` を作成)、Esri Ocean Basemap | 約450m |
| 地図・航空写真・陰影起伏図 | 国土地理院 地理院タイル | 高解像度 |
| 雲なし衛星写真 | Sentinel-2 cloudless (EOX) | 10m |

## 見るときの注意

- 衛星が測れるのは海の表面だけです。海底の水温・酸素・魚そのものは見えません。
- 雲がある日は衛星データが空白になります。陸のすぐ近くも値が出にくいです。
- 生き物の適水温は一般的な目安です。佐賀県玄海水産振興センターなどの資料や、漁師さんの経験と合わせて判断してください。
- 対馬暖流の線は大まかな向きの模式図です。日々の流れは「海しる」で確認できます。
- 地名の点は Wikipedia などで確かめた座標です。陸地のデータは100万分の1の精度なので、小さな入り江(名護屋浦など)は陸地に埋もれて見えることがあります。
- 「風を正面から受ける海岸」は海岸の向きと風よけの有無から計算した目安で、実際にごみがたまるかは浜の形や潮の流れでも変わります。

## まだ地図に載せられていない調査データ

海底の泥・砂(底質)や、海底近くの溶存酸素の長い記録は、次の資料にあります。PDFや表で公開されていて座標が付いていないため、元の表が手に入れば地図に重ねられます。

- 佐賀県「唐津市沖洋上風力発電事業誘致に係る漁業環境影響調査」報告書(概要版)
- 佐賀県「唐津湾の海岸侵食対策について(提言)」の底質調査
- 佐賀県海況テレメータシステム(名護屋浦・仮屋湾の底層の溶存酸素、30分ごと)
- 佐賀県玄海水産振興センター 業務報告書
- 佐賀県 公共用水域水質測定結果(COD・窒素・りん)
- Karatsu Data Bank(水揚げ・海ごみ)

## 月平均データの作り方

NOAA ERDDAP はブラウザから直接読めないため、`tools/build_history.py` を GitHub Actions(`.github/workflows/umi-map-data.yml`)で動かし、
唐津周辺の約5km間隔の格子で2002年6月からの月平均水温を `data/history.js` に書き出しています。
スクリプトを変更して送ると、自動で取り直します。

## これから足したいこと

- JAXA「しきさい」(GCOM-C)の250m解像度データで、湾の中をもっと細かく見る
- 海流(JCOPE などの海洋モデル)の矢印表示
- 漁師さんの船や定置網につけた水温計の値を地図に重ねる
- 環境DNA調査の結果(どの魚がいたか)を地点ごとに表示
- 航空写真の新旧比較で、藻場の面積の変化を測る

`vendor/leaflet/` には地図ライブラリ Leaflet 1.9.4(BSD-2-Clause)を同梱しています。
