地形を見る

宇宙から見た海

「むかしと比べる」を押すと、地図の左半分が比べる日、右半分が見る日になります。真ん中の朱色の丸を左右に動かしてください。

海の上をクリックすると、その地点の水温とプランクトンの量を数値で表示し、20年間の水温の変化も調べられます。

なぜ魚が減ったのか

公表されている調査と、この地図の20年分の衛星水温からわかることです。原因は1つではなく、いくつかが重なっています。

  1. 夏の海が熱くなった衛星の月平均で、7月は20年前より約1.9℃、9月は約1.2℃高い。一方、冬(12〜3月)はほとんど変わっていない。2026年8月は県の観測5地点すべてで平年より1.5〜2.6℃高かった。
  2. 魚のゆりかご(藻場)が半分になった玄海の藻場は1,262ha(2013年)から597ha(2022年)へ。南方系のウニ「ガンガゼ」などが海藻を食べ尽くす磯焼けが主な原因とされる。藻場は多くの魚の産卵場・稚魚の隠れ家。
  3. 回遊してくる魚・イカの来方が変わった佐賀県のケンサキイカは2018年に305tで、30年前の約5分の1。対馬暖流や日本海の水温の変化が関係すると考えられているが、はっきりした原因はまだわかっていない。代わりにブリ・サワラなど暖かい海の魚が増えている。
  4. 漁をする側も減った玄海地区の漁獲量は2011年の9,570tから2020年の2,660tへ約7割減。資源の減少に加え、漁獲の半分以上を占めていた大型まき網が2015年に撤退したことも大きい。高齢化・燃料代・魚の値段も重なる。
まだわからないこと・確かめ方
  • 海の底のようす: 衛星は海面しか見えない。海底近くの水温や酸素は県のテレメータ(名護屋浦・仮屋湾)の記録が手がかり
  • 魚の種類ごとの漁獲の変化: 県の水産統計や漁協の水揚げ記録、定置網の記録(佐賀県の研究報告に1983〜2010年の分析あり)
  • いまどの魚がいるか: 海水から魚の種類がわかる環境DNA調査

いまの海に合う生き物

それぞれの生き物にとって住みやすい水温の月が、昔と今で何か月あるかを比べます。地図をクリックすると、その場所の水温で計算し直します。

海面の水温だけで見た目安です。海底は海面より冷たいことが多く、エサ・流れ・海藻・獲り方でも魚の数は変わります。適水温は一般的な文献値をまとめたもので、成長段階でも違います。

年ごとに比べる

同じ場所の写真を2つの年で並べ、真ん中の朱色の丸を左右に動かして見比べます。海藻の森は浅い岩場の上の黒っぽい影、磯焼けした所は白っぽい岩肌に見えます。

見る場所

衛星写真(Sentinel-2)は10m単位で、その年の雲の少ない日を合成したものです。細かい海藻の種類まではわかりません。気になる場所が見つかったら「海の記憶ピン」で印をつけ、潜って確かめるのが次の一歩です。

これからの予定(Isoyake Watch)
  • 記録する: 潜水記録(場所・日付・海藻の被度・ウニの数・写真)を地図に残し、潜る候補の順位を、理由が見える決まりで出す
  • 当てる: 1シーズン分の潜水記録を答えにして、衛星画像から藻場の変化を見つける仕組みを作り、当たり具合を確かめる

唐津の調査データ

県や市が公表している調査結果です。衛星では見えない海の中のようすを補います。

玄海の藻場の面積1,262ha → 597ha2013年 → 2022年。約10年で半分以下
玄海地区のウニ漁獲量約200t → 15t約35年前 → 2024年
2026年8月4日の表層水温+1.5〜2.6℃県の5地点すべてで平年より高い
ガンガゼ(海藻を食べるウニ)の駆除年86万個漁業者グループによる駆除(報道)

藻場が減った主な原因は、温暖化で増えた南方系のウニ「ガンガゼ」による食害とされています。アイゴなど海藻を食べる魚の影響も指摘されています。

まだ地図に載せられていないデータ
  • 海底の泥・砂(底質):佐賀県の唐津市沖 漁業環境影響調査 報告書(概要版)、唐津湾 海岸侵食対策の提言(底質調査)
  • 海底近くの酸素(溶存酸素)の記録:県テレメータ(名護屋浦・仮屋湾の底層)、玄海水産振興センター 業務報告書
  • 水質(COD・窒素・りん):県の公共用水域水質測定結果。令和5年度は玄海水域の一部の基準点でCODの環境基準が未達成
  • 藻場の分布図:県が衛星写真と潜水調査で行った玄海地区の藻場調査
  • 水揚げ・海ごみ:Karatsu Data Bank(唐津Farm&Food)

これらはPDFや表で公開されていて、地点の座標が付いていないものが多いです。市や県から元の表をもらえれば、地図に重ねられます。

海ごみ

唐津の玄海側の海岸には、海外からのものも含めて大量のプラスチックごみが流れ着きます。対馬暖流、冬の北西の季節風、狭い海峡、入り組んだ海岸が重なるためと県は説明しています。

漂着ごみのうちプラスチック約8割うち約6〜7割が海外製(県)
波戸岬のビーチクリーン2,310袋燃えるごみ。延べ14回・2,250人(2025年10月まで)

朱色の濃い線ほど風を真正面から受けます。実際にごみがたまるかは、浜の形(砂浜か岩場か)や潮の流れでも変わります。漁師さんや清掃をしている方の記録をピンで重ねると確かになります。

海の記憶ピン

漁師さんや地域の方の「昔はここで獲れた」「最近ここに増えた」を地図に残します。衛星のデータと重なる場所に、問題の手がかりがあります。

ピンはこの端末のブラウザに保存されます。ハッカソンでは「ファイルに保存」で集めて、1つにまとめられます。

見方の注意

衛星が測れるのは海の表面(数メートル)だけです。海底の水温・酸素・魚そのものは見えません。雲の日は空白になります。生き物の適水温は一般的な目安なので、地元の水産試験場や漁師さんの経験と合わせて判断してください。

データの出典
  • 海面水温・平年差: NASA JPL MUR SST (GHRSST) / 表示 NASA GIBS、数値 NOAA CoastWatch ERDDAP
  • クロロフィル・その日の衛星写真: NOAA-20 VIIRS(2018年ごろ以降)、NASA MODIS Aqua / Terra(それ以前)
  • クリック地点の水温: Open-Meteo Marine(その日の値)、NASA MUR の月平均(NOAA ERDDAP から同梱)
  • 潮の流れ・波・いまの水温: Open-Meteo Marine API(Météo-France SMOC ほか)
  • 観測点の水温: 佐賀県玄海水産振興センター 漁場環境情報
  • 藻場・ウニ: 佐賀県の藻場調査(佐賀新聞)、水産庁 磯焼け対策全国協議会資料、サガテレビ報道、唐津市 ブルーカーボン
  • 海ごみ: 佐賀県、唐津Farm&Food、いまの風: Open-Meteo
  • 陸地・市町の境界: 国土地理院「地球地図日本」(jpn-atlas 経由)
  • 地名の位置: Wikipedia ほかで確認した座標
  • 海底地形図: GEBCO 2024 Grid(約450m単位)から色分けと等深線を作成、Esri Ocean Basemap
  • 地図・航空写真・陰影起伏図: 国土地理院 地理院タイル
  • 衛星写真: Sentinel-2 cloudless by EOX (Copernicus Sentinel data)
  • もっと詳しく: 海しる(海上保安庁)、JASMES(JAXA しきさい)
